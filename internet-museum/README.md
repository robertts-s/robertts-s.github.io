## Esto no es una colección de textos

Internet Museum está pensado como un lugar que se explora poco a poco. Cada sala contiene archivos interactivos, líneas temporales, recreaciones visuales, sonidos y pequeños secretos.

Abre tarjetas, prueba los botones y presta atención a los elementos que parecen decorativos. Algunos archivos no aparecen en el mapa.

> Cinco salas. Quince archivos. Cinco señales sonoras. Tres objetos ocultos.

## Las salas

### 01 · Internet de los 2000

Messenger, Tuenti, Fotolog y los minijuegos Flash. Una época de zumbidos, nicks interminables, contadores de visitas y perfiles que parecían habitaciones digitales.

### 02 · Sistemas Operativos Legendarios

Windows 95, Windows XP, Ubuntu clásico y los escritorios que convirtieron sonidos, fondos de pantalla y menús en recuerdos compartidos.

### 03 · Móviles que cambiaron el mundo

Nokia 3310, BlackBerry y el primer iPhone. Del teclado físico y las baterías eternas a llevar Internet completo en el bolsillo.

### 04 · Consolas y videojuegos

Game Boy, Nintendo DS, PSP, PlayStation y PS2. Máquinas que demostraron que una pantalla pequeña o un disco rayado podían contener mundos enormes.

### 05 · Internet curioso

La primera web, páginas que se negaron a envejecer, código fuente y easter eggs históricos. La parte extraña de Internet también merece conservarse.

## Cómo funciona la visita

- El **mapa** permite acceder a las cinco salas.
- Cada tarjeta abre un archivo con contexto y datos curiosos.
- Las microexperiencias recrean interfaces, juegos y acciones históricas.
- El **pasaporte digital** registra descubrimientos y logros.
- La barra de progreso muestra cuánto queda por explorar.
- El estado se conserva en el navegador mediante `localStorage`.
- Al completar las condiciones necesarias se abre el archivo final.

| Logro | Condición |

| **Archivo sonoro** | Escuchar las cinco señales históricas |
| **Memoria completa** | Registrar todos los descubrimientos |

## Tecnología

- HTML semántico y `dialog` nativo.
- CSS responsive con recreaciones visuales sin imágenes externas.
- JavaScript basado en datos para generar salas y artefactos.
- Web Audio y archivos históricos opcionales con fallback sintetizado.
- Persistencia local de progreso, secretos y logros.
- Accesibilidad mediante teclado y soporte para `prefers-reduced-motion`.

## Contenido histórico

Las piezas visuales incluidas son recreaciones editoriales hechas con HTML y CSS. Los sonidos propietarios no se distribuyen con el proyecto: pueden añadirse copias obtenidas legítimamente siguiendo las indicaciones de [`assets/audio/README.md`](assets/audio/README.md).

Antes de publicar capturas, logotipos o sonidos originales, deben revisarse sus derechos de uso y conservarse los créditos correspondientes.
