## No es un portfolio normal

`roberttsOS` transforma una web personal en un escritorio interactivo. En lugar de desplazarte por una página convencional, abres ventanas, ejecutas comandos, descubres aplicaciones y juegas con distintas piezas del sistema.

Está inspirado en terminales, sistemas operativos clásicos y la sensación de encontrar software extraño en un ordenador que no es el tuyo.

> Entra por curiosidad. Abre cosas. Prueba comandos. Puede que haya más de lo que parece.

## Qué encontrarás

- Un escritorio con ventanas móviles, minimizables y redimensionables.
- Un terminal interactivo con comandos y accesos a aplicaciones.
- Proyectos y enlaces personales presentados como archivos del sistema.
- Versiones jugables de **Snake** y **Tetris**.
- Una mascota virtual con acciones, estadísticas y eventos.
- Un mural colectivo: **“Antes de morir quiero...”**.
- Acceso al **Internet Museum** y al **Flipper IR Macro Builder**.
- Diseño responsive con estética terminal, scanlines y fondo animado.

## Tecnología

El proyecto está construido principalmente con:

- HTML, CSS y JavaScript sin frameworks.
- Canvas para animaciones y juegos.
- Web Audio para sonidos interactivos.
- `localStorage` para conservar puntuaciones y progreso.
- Firebase para experiencias colectivas configurables.
- GitHub Pages para el despliegue.

## Estructura

```text
roberttsOS/
├── index.html                 # Escritorio principal
├── internet-museum/           # Museo digital interactivo
├── ir-macro-builder/          # Constructor de macros IR
├── pet/                       # Mascota virtual
├── Remote_TVs/                # Colección de mandos infrarrojos
└── assets/                    # Configuración y recursos compartidos
```

## Ejecutarlo localmente

Puedes abrir `index.html` directamente. Para que todas las rutas y peticiones funcionen como en GitHub Pages, es preferible usar un servidor estático:

```bash
python3 -m http.server 8000
```

Después visita `http://localhost:8000/`.
