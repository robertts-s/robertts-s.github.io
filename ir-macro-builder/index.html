USO — ARCHIVO .IR
1
Selecciona una marca y modelo de mando
2
Pulsa los botones para añadirlos a la secuencia. Puedes combinar botones de distintos mandos
3
Ajusta el delay de cada señal arrastrando para reordenar
4
Descarga el .ir → cópialo en SD/infrared/
5
Flipper → Infrared → Open file → tu macro aparece como un solo botón
COMPILAR COMO APP NATIVA (.FAP)
1
Descarga el .c generado
2
git clone --recursive github.com/flipperdevices/flipperzero-firmware
3
Copia la carpeta ir_macro/ en applications_user/
4
./fbt fap_ir_macro → genera el .fap
5
Copia el .fap a SD/apps/Infrared/
