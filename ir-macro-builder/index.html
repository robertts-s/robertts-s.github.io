CÓMO USAR EL ARCHIVO .IR
1
Descarga el archivo .ir generado
2
Cópialo a la SD del Flipper en: SD/infrared/
3
En Flipper: Infrared → Open file → selecciona tu archivo
4
Aparecerá tu botón macro. Pulsarlo envía toda la secuencia automáticamente
CÓMO USAR EL CÓDIGO C
1
Requiere Flipper Zero Firmware SDK
2
Crea una carpeta en applications_user/ir_macro/
3
Guarda el .c y crea un application.fam con appid y entry_point
4
Compila con ./fbt launch_app APPSRC=applications_user/ir_macro
⚠ El .ir es el método más simple y no requiere compilación.
El código C crea una app nativa que aparece en el menú del Flipper.
